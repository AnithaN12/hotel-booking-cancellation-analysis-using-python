# 🏨 hotel-booking-cancellation-analysis-using-python

Data-Driven Insights & Revenue Optimization Strategies

📌 Project Overview

An Exploratory Data Analysis (EDA) project on 119,390 hotel booking records (2015–2017) to identify cancellation patterns, seasonal demand, pricing trends, and revenue leakage.

The project compares City and Resort Hotels and provides actionable strategies to improve occupancy and revenue management.

🎯 Objectives
* Analyze booking cancellations across hotel types.
* Identify monthly and seasonal booking trends.
* Understand the relationship between ADR and cancellations.
* Identify countries contributing to cancellations.
* Recommend strategies to reduce revenue loss.

📊 Key Insights
* 37.13% overall booking cancellation rate.
* 41.71% cancellation rate for City Hotels.
* 27.97% cancellation rate for Resort Hotels.
* August recorded the highest booking volume.
* Portugal accounted for 70.08% of cancellations in the reported country analysis.
* Canceled bookings showed higher average ADR than completed bookings.
  
🛠️ Tech Stack
* Python
* Pandas & NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook
  
🔍 Analysis Performed
* Data Cleaning & Preprocessing
* Reservation Status Analysis
* Hotel-wise Cancellation Analysis
* Monthly Booking Trends
* Average Daily Rate (ADR) Analysis
* Country-wise Cancellation Analysis
* Canceled vs. Non-Canceled ADR Comparison
  
💡 Business Recommendations
* Introduce targeted non-refundable booking options.
* Apply data-driven overbooking strategies.
* Strengthen group booking cancellation policies.
* Optimize seasonal pricing strategies.
* Develop targeted campaigns to recover canceled bookings.
 
📈 Expected Outcome

This analysis helps hospitality businesses understand cancellation behaviour, improve demand forecasting, optimize room inventory, and make data-driven revenue management decisions.
